# OpsPilot

An AI-powered procurement and operations copilot.

## Overview

OpsPilot helps organisations automate document retrieval,
invoice processing, purchase order reconciliation,
and approval-based workflow automation.

## Technology Stack

- Python
- FastAPI
- PostgreSQL + pgvector
- OpenAI API
- Streamlit
- Docker

## Project Status

Milestone 0: Project initialisation.

## Data

This project uses synthetic procurement documents.
